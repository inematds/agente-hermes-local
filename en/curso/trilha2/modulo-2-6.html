🖥️ The desktop app

The most user-friendly way into Hermes is the desktop app. It looks like a chat app: you open it, start a session, and chat — without having to memorize commands. If you find the terminal intimidating, this is a good place to start.

Tip: the desktop app and the terminal are two ways to access the same agent. Choosing one doesn’t turn the other off—it’s a matter of comfort. Start in the app; move to the terminal when you want commands.

Key concepts

Desktop app

Graphical chat interface for Hermes.

Less intimidating

A good starting point for beginners.

New session

Starts a new conversation with the agent.

Same engine

The app and terminal talk to the same agent.

⌨️ The terminal

For those who like control, Hermes also lives in the terminal. You’ve already seen some commands (update, status, doctor). Here are two more: hermes dashboard, which opens the panel, and hermes setup, for the initial setup.

🎯 Objective

Open the Hermes panel and (if you haven’t already) run the initial setup — all from the command line.

hermes setup

How to verify: hermes dashboard open the agent panel; hermes setup guides the initial setup. To check that everything is healthy beforehand, remember to hermes status e hermes doctor (module 2.5).

💬 Telegram: the agent in your pocket

The third way in is the most surprising: you can talk to your agent through Telegram, as if it were a contact. You send a message from your phone, and Hermes — running on your machine at home — replies. Your local agent is accessible from anywhere through a chat app you already use.

📲 What this unlocks

  • •Mobility: talk to the agent without being at the computer.
  • •Familiarity: the interface is the Telegram chat, which you already know.
  • •Continuity: the intelligence lives on your machine; your phone is just the remote control.

Privacy note: using Telegram puts a messaging app in the middle. For tasks involving sensitive data, remember the modes from Track 1 — you’ll explore this further in Project 7 (Track 3), where the agent on your phone is the main focus.

Key concepts

Telegram

Talk to the agent through a chat app.

Remote control

Your phone is in charge; the brain stays at home.

Mobility

Access from anywhere.

🗂️ Sessions: conversations that persist

A session and a conversation saved with the agent. You start a "New session", work in it, close the app—and you can come back later and pick up right where you left off. Unlike an ephemeral chat, the session persists: the context for that task is saved.

🌿 Branch / fork a chat

Here's a powerful feature: you can fork a conversation. At any point, the chat splits into two lines that start from the same history but follow different paths — like a fork in the road. Useful for exploring two approaches without losing either one.

New here? "Branch" and "fork" come from the world of code: they mean creating a copy that starts from a common point and continues on its own. In a conversation, this lets you test "what if I asked another way?" without deleting the original version.

In the fork point, the conversation splits: the branch A tests one path and the branch B another, both starting from the same history. You compare the two without losing either—ideal for "what if I tried another way?".

Key concepts

Fork / branch

Split a conversation into two branches.

Regular history

Both lines start at the same point.

Explore in parallel

Test approaches without losing the original.

Without destroying

The starting version stays intact.

📦 Artifacts: save and view outputs

When the agent produces something concrete—a file, a code snippet, a document—that becomes a artifact. Instead of getting lost in the middle of the conversation, the result is saved as an object you can view, open, and reuse later. That's how Hermes keeps your work from slipping away in the chat.

📦 Why artifacts matter

  • •The result isn't lost: the output stays separate from the chat.
  • •Reusable: you return to it later, in another session.
  • •Tangible: the agent’s work becomes something you can save, not just text scrolling on the screen.
